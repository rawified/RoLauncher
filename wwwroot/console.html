Playing

Lets you run more than one Roblox window, for example one per account. Close all Roblox windows before turning it on. Only one game can be shown inside the launcher; the others open in their own windows.

Discord

Advanced: use your own Discord application

Leave this empty to show up as RoLauncher. To show a different name, create an application at discord.com/developers/applications and paste its Application ID here.

Discord needs to be open on this PC (the desktop app). Your status only goes to your own Discord app; RoLauncher doesn't send it anywhere else.
